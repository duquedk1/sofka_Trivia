# Sofka Trivia Game

Sofka Trivia is an interactive web-based quiz game developed as part of a personal project to test and enhance programming skills in JavaScript, HTML, and CSS. This trivia game allows users to test their knowledge across various categories, with each correct answer earning points. The game is designed to be engaging, fun, and easy to play.

## Features

- **Multiple Categories**: Users can choose from different trivia categories to test their knowledge.
- **Randomized Questions**: The questions are randomly selected to ensure a unique experience every time the game is played.
- **Scoring System**: Players earn points for each correct answer, and their final score is displayed at the end of the game.
- **Responsive Design**: The game is fully responsive and can be played on both desktop and mobile devices.
- **User-Friendly Interface**: Simple and intuitive interface that makes the game accessible to users of all ages.

## Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6)
- **Version Control**: Git & GitHub for project management and collaboration.

## How to Play

1. Choose a category to start the game.
2. Answer the multiple-choice questions presented on the screen.
3. Accumulate points by answering correctly.
4. Check your final score once the trivia session ends.
